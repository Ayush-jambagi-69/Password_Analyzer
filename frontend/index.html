      How to read this. Having several character types raises the theoretical pool size, but it does not make a password strong. Real attackers try dictionary words, keyboard patterns and leaked passwords first. The heuristic estimate subtracts bits for patterns this page can recognise; it is a teaching aid and ignores anything it does not know about (for example, a password that is already in a breach list). Its thresholds (28, 36, 60 and 80 bits) are conventional rules of thumb, not scientific limits.

    Suggestions

      How to read this. Having several character types raises the theoretical pool size, but it does not make a password strong. Real attackers try dictionary words, keyboard patterns and leaked passwords first. The heuristic estimate subtracts bits for patterns this page can recognise; it is a teaching aid and ignores anything it does not know about (for example, a password that is already in a breach list). Its thresholds (28, 36, 60 and 80 bits) are conventional rules of thumb, not scientific limits.

      Nothing to improve yet

      Enter a password above. You will get three levels of suggestions: Moderate, Strong and Very Strong.

      Pick a level

      Good to know. "Your password, upgraded" keeps what you remember and adds random words, so only the added part is truly random. Its strength is an estimate: if your starting password is a common word, prefer a fully random option. Random options are drawn with your browser's secure random generator, and each bit counted is exact for those. Never reuse one password on several sites, and a password manager is the easiest place to keep them.
      No. 03 · Combinatorics Lab

      Combinatorics Lab

      Configure a password format, then see its character pool, search space, entropy, constrained counts and guessing-time estimates.

      New here? How to use this page 2 min read

      What this page does: you describe a kind of password (how long, which characters) and it counts how many different passwords of that kind exist, and how long a computer would need to try them all. You never type a real password here.

      1. Choose a format on the left: a length and which character types are allowed.
      2. Read "In plain words" on the right, then the numbers below it. They update as you change anything.
      3. Watch the charts. They show what happens if the password were longer, or if more character types were allowed.
      4. Optional rules: tick "require at least one" to count only passwords that follow a site's rule, such as "must contain a digit".

      No. 04 · Comparison

      Password Comparison

      Compare two generated-password formats. No real passwords are needed.

      New here? How to use this page 1 min read

      What this page does: it puts two password formats side by side so you can see which one is harder to guess, and why: because it is longer, or because it allows more kinds of characters.

      1. Press a quick example below (for example "8 lowercase vs 12 lowercase"), or set Configuration A and B yourself.
      2. Read the table: a higher entropy (bits) and a bigger search space mean harder to guess by brute force.
      3. Read "What changed": it splits the difference into a length part and a character-types part.
